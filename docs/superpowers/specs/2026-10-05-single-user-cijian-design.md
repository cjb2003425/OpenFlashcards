# OpenFlashcards 单用户词间融合设计

## 目标

以 `Liozon/OpenFlashcards` 为完整的新应用基础，替换当前局域网生词本。保留上游的翻卡、拼写、短语、TTS、统计、离线模式和笔记本，同时融合本机中文释义生成和 A4 陌生度测验打印。

## 单用户模式

- 浏览器打开应用后直接进入主界面，不显示登录页。
- 服务端为所有请求注入固定本地用户 `local`，不暴露用户管理或退出入口。
- 数据使用 OpenFlashcards 原生 JSON 格式，保存在单独的数据目录。
- 不迁移旧“词间”浏览器数据。
- 首次启动时预配置中文为母语、英语为目标语言和中文界面。

## 中文释义自动生成

- 在添加英语单词时，输入停止约 700 毫秒后调用同源翻译接口。
- 服务端优先查询本机 ECDICT；未命中时调用本机 MarianMT 英译中模型。
- 结果只在释义为空或仍为上一次自动结果时写入，不覆盖用户手工修改。
- 翻译失败不阻断手工新增单词。

## A4 测验打印

- 主导航增加“打印测验”。
- 服务端从当前英语词库中排除已打印单词，并按 `progress / maxProgress` 升序排列，掌握度越低越优先。
- 每批最多 30 题，A4 纵向双栏；只显示中文释义和英文填写横线，不附答案。
- 点击打印时立即持久化 `printedAt`，下批不再选取；词库页面显示“已打印”。
- 支持清除当前语言的全部打印标记并重新开始一轮。

## 部署与回滚

- 新版先在备用端口运行并完成 API、浏览器和 A4 单页 PDF 验证。
- 验证通过后，将现有 systemd 用户服务切换到 OpenFlashcards，继续使用 `8090`。
- 旧 `/home/torrey/sites/cijian-vocab` 文件保持不变，可随时回滚。

## 验证

- 单用户启动无需登录，管理员入口和退出入口不可见。
- 新增英语单词时自动填充中文释义。
- 打印批次按陌生度排序，连续批次不重复，刷新后标记仍保留。
- 30 题输出为一张 A4，不包含答案。
- 上游核心页面、TTS 路由和数据保存仍可用。
